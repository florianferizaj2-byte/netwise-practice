## 两轮审核

1. 查重：对照现有网络工程师题库的 490 道题（原创 47 道、用户汇编 443 道），检查题干及考查点；另做规范化文本与近似题扫描。
2. 内容：逐题核对选项唯一性、答案、推理解析和所属知识点；事实性标准与法律题按审核记录中的权威来源核对。

## 文件

- `questions/`：按大类分文件的题目 JSON，后续可按服务器最终分类重新映射。
- `review-record.json`：覆盖数量、查重及内容审核记录。
- `audit-draft.mjs`：复核草稿数量、分类、答案位置、重复选项、现有题库相似项及人工判定；执行 `node audit-draft.mjs` 可重建审核记录。
- `apply-server-taxonomy.mjs`：将草稿映射到服务器最终知识点，并更新正式题库和分类计数。
- `server-taxonomy-import-record.json`：记录新分类映射与入库后的各知识点题量。
