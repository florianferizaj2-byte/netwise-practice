# 作者 AI 服务与多模型管理

解析、提示、错因分析、学习计划和 AI 出题统一连接作者的服务；学习记录、题组所有权与积分仍按使用者账号独立保存。普通用户不需要配置个人 API。

## 管理中心：AI 服务配置

默认保留现有单接口，不自动改写 DeepSeek、环境变量或已保存密钥。管理员可添加多个国内模型连接，确认价格后再主动启用“优先级模式”。

1. 预设支持 DeepSeek、阿里云百炼 / 通义千问、智谱 GLM、火山方舟 / 豆包、Kimi、硅基流动；也可添加其他 Chat Completions 文本兼容接口。每个连接独立保存名称、地址、模型、加密密钥、启停和优先级。
2. 优先级数字越小越靠前；上下移动会重新编号并立即保存。启用优先级模式后，所有正常 AI 功能选择最靠前的已启用、密钥存在且价格有效的连接，覆盖原单接口来源。缺价、价格过期、成本待核对或停用连接会在发请求前跳过；全部不可用时停止调用，不暗中回退原密钥。
3. 已发出的请求失败时结束并退还整个任务的预扣积分，不自动向其他付费服务重试。后续新任务可以选择仍然就绪的下一接口。
4. “复制原连接到列表”只生成停用副本，不改原配置；切回原单接口后恢复原有配置优先顺序，列表和历史账单保留。
5. 更换服务地址必须重新输入对应密钥或明确清除旧密钥。密钥只在服务端加密保存，配置响应、审计记录和客户端均不返回明文。列表使用版本号防止多页面覆盖，价格与连接更新在同一事务提交。

### 价格提示与计费

- 显示输入 / 输出 / 缓存输入的人民币每百万 Token 成本，以及 1,000 输入 + 1,000 输出的成本和积分示例。示例不包含缓存折扣，最终仍按实际用量和任务结果结算。
- 官方参考价与“已确认成本价”明确分开。未收录参考价时显示待核价及官方价格链接，不展示零元。填入参考价不会自动确认或启用。
- 价目按服务地址 + 精确模型名绑定；同地址同模型的多个密钥共用价目，不适用于不同密钥各自的优惠价。新地址、新模型不能套用 DeepSeek 价格。
- 管理员确认自己的区域、模式与适用最高档费率，填写依据及最多 31 天的复核有效期。接口仅支持三项 Token 成本，不支持工具收费、缓存写入 / 存储等额外账单维度；Kimi K3 当前明确阻止添加。
- 连接测试需显式确认，会调用选定连接、消耗当前管理员积分并记录成本；不改变首选连接，不使用其他用户积分。测试输出上限为 256 Token。新增或编辑连接不会自动发送测试请求。
- 可选择 include_usage 流式、原生流式用量或非流式 JSON，配置对应思考参数。Kimi K2.6 按官方约束省略温度参数（包括独立审校），不降低 Schema、计算或审核标准。上游用量无法核实时退款并暂停该地址 / 模型，先在“用量与成本”核对真实账单，再恢复。

预设与参考信息核对于 2026-10-24；模型名、地域和价格仍以账号控制台为准：[DeepSeek](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[百炼](https://help.aliyun.com/zh/model-studio/model-pricing)、[智谱](https://docs.bigmodel.cn/cn/guide/start/pricing)、[火山方舟](https://console.volcengine.com/ark/region%3Acn-beijing/docs/base-url-and-authentication)、[Kimi](https://platform.kimi.com/docs/guide/kimi-k2-6-quickstart)、[硅基流动](https://docs.siliconflow.cn/docs/userguide/quickstart)。预设不代表已用真实 API Key 验收。

## 服务配置

未启用优先级模式时，后端按以下顺序选择一个完整的作者配置：

1. 服务器 `AI_SERVICE_API_KEY`、`AI_SERVICE_BASE_URL`、`AI_SERVICE_MODEL`。
2. 兼容原服务器 `AUTHOR_API_KEY`、`AUTHOR_API_BASE_URL`、`AUTHOR_API_MODEL`。
3. 主管理员已保存的普通 AI 设置；若没有密钥，再使用该主管理员的“管理员 API”设置。

主管理员优先由 `AI_SERVICE_OWNER_ID` 指定，其次为 `ADMIN_USERNAME` 对应的管理员；两者都未设置时使用最早的有效管理员。显式指定的账号不存在或不是有效管理员时，不会改用其他用户的密钥。匿名开发实例没有账号时兼容本地作者配置。

环境变量中的 Base URL 和 Model 未填写时，官方 DeepSeek 默认使用 `https://api.deepseek.com` 和 `deepseek-flash`；显式保存的模型不自动迁移。两组环境配置分别配套使用，避免把一家的密钥发送到另一家的地址。

原单接口仍由主管理员在网页“设置”或 App“我的 → AI 学习助手”管理。单接口模式下环境配置优先于页面保存的配置；多接口模式使用管理中心的列表，修改原表不改变列表。普通用户只看到服务状态和积分入口。

密钥不返回给普通用户、不复制到各用户设置、不打包进 APK 或移动网页。真实密钥只保存在服务器私有环境或加密配置中，沿用原有 `AI_MASTER_KEY`。

## 积分结算规则

AI 已统一使用积分，不再按解析 / 出题 / 分析次数扣额；详细规则见 `docs/ai-points-plan.md`。

- 调用前按当前地址与模型的有效成本价预扣积分和成本预算；不足时不访问上游。成功后按实际 Token 与价格结算，多退少补。
- 同一任务包含生成、校验、重试和独立审校，最终失败时退还整个任务的用户积分，真实上游成本仍记录。
- 已缓存结果、确定性判分及普通刷题不重复扣积分；同一逻辑请求的成功结果回放也不重复收费。
- 价格未知、过期或用量不可核实时停止新调用，不把未知成本当作免费。积分余额与销售实收分开记账，会员码不自动虚构收入。
- 学习计划由用户主动请求，后台定时器不自动消费账号积分。

## AI 输出成本控制

所有上游请求均由服务端设置 `max_tokens`，配置页或调用方传入超大上限也不能越过任务硬上限。策略集中在 `server/ai-output-policy.js`：

| 任务 | 首次上限 | 截断重试上限 |
| --- | ---: | ---: |
| 解析 | 900 | 1800 |
| 分级提示 / 提示复核 | 256 / 128 | 512 / 256 |
| 错因分析 / 学习计划 | 800 / 1200 | 1600 / 2400 |
| 短课生成 / 内容审校 / 判分 | 6500 / 2200 / 800 | 10000 / 4400 / 1600 |
| 精炼与互动课程答疑 / 答疑复核 | 2048 / 700 | 4096 / 1400 |
| n 道出题（n 为 1—20） | 800 + 1200n | 1600 + 1800n |
| n 道独立审题 | 256 + 320n | 512 + 640n |
| 连接测试 | 256 | 不扩容 |
| 其他调用兜底 | 2048 | 4096 |

解析默认约 180—280 字，复杂题可到 450 字，保留必要条件、公式、单位及关键推导。出题保留全部题目与字段，不通过缩减题量、放松 Schema、计算校验或独立审题来省成本。截断时只在现有尝试次数内有界扩容；达到上限仍未完整输出则失败并退款，不返回半截结果。用量日志记录实际 `outputTokenLimit`，可结合真实调用数据继续校准。

## 移动网页屏幕适配

普通浏览器使用动态视口高度；iOS 主屏幕应用使用完整窗口高度，避免启动阶段较小的 `visualViewport` 被固定下来。只有输入框聚焦且软件键盘实际压缩可见区域时，才用测量高度避让键盘。

窗口大小、横竖屏、重新回到页面、主屏幕模式和焦点变化都会同步布局。底栏不参与内容压缩，滚动内容可缩小；保留设备安全区，底部安全区使用与底栏相同的背景。

浏览器行为依据：[WebKit 动态视口说明](https://webkit.org/blog/12288/working-together-on-interop-2022/) 与 [MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)。真机 Safari、不同 iOS 版本和安装到主屏幕后仍需分别验收。

## 部署

1. 保留服务器原有 `.env`、`AI_MASTER_KEY`、数据库和用户上传文件；先按原部署流程备份。
2. 同步新版后端，包括 `server/ai-service*.js`、积分模块以及入口和存储接入。启动时仅自动创建多接口所需的两张表，默认单接口模式；不清库、不复制真实密钥到客户端、不自动新建启用连接。
3. 安装根目录和 `mobile` 依赖，运行 `npm run build`，完整发布 `dist/` 与 `dist/app/`，重启原 Node 服务。
4. 多模型管理入口在 Web 管理中心；后端统一路由与结算同时服务 App 和小程序，不要求把新密钥打包进客户端。
5. iPhone / iPad 在“我的”里刷新到最新版本，或关闭后重新打开主屏幕应用。

此次未改写生产数据库或真实作者 API 凭证。正式启用需要服务器配置可用的作者密钥并部署新版后端。
