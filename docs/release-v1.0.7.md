# 考匠 v1.0.7

Android `com.kaojiang.app`，版本 `1.0.7` / versionCode `40`。本轮修复音频重复播放；APK 与源码按现有 GitHub 分支交付，线上部署仍由维护者执行。

## 修复

- Android 播放器播完进入 STATE_ENDED 时，直接的 isLoaded 会变为 false，但完整状态仍表示源已加载。旧代码在 seekTo(0) 前就返回，因此同一条语音/提示音往往只能播一次。
- 统一识别“已加载或正常播完可重播”的状态，覆盖内置答对音、按钮音效与已下载语音包。播放前从头定位；加载中、损坏或已释放的播放器仍不会强行播放。
- 每个新的作答结果不再被最小播放间隔吞掉；“答对 → 答错 → 再答对”和连续多次正确可再次触发。重复回执仍按作答 ID 去重，离开题目或切后台后取消迟到声音。
- 进入练习目录、加载中或空页面不播放入场语音；实际题目加载且可见后才触发，同一轮的上一题、下一题及重新渲染不重复播报。
- 本次未改变系统静音行为、手机音量或 App 独立音量开关。语音包协议/文件不变，不需要重新下载已有包。
