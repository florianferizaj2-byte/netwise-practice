# 考匠 v1.0.11

Android `com.kaojiang.app`，版本 `1.0.11` / versionCode `44`，沿用正式签名覆盖升级。

## 本次更新
- AI 生成位于底部导航正中；采用统一蓝白界面，将首页、分析、设置、方案、进度、作答、成绩、解析与记录拆为独立页面。
- 根据当前账号、当前证书的不同题目作答证据，提供攻克不会的、挑战更难的、巩固易忘的与综合提分。样本不足先诊断，不把重复答对当作稳定掌握。
- 练习与考试复用相同画像、方案和质量校验；确认积分规则后才生成。
- 生成任务、题目位置、交付事件和作答版本持久保存。首批3题就绪即可作答，后续题目审核通过后逐题加入。
- 断线不取消后台任务；本机作答暂存、重连同步，冲突或超时改动单独归档。迟到的旧响应不会退回已开始的作答页面。
- 考试仅在服务器确认已交付题目全部作答且仍缺题时暂停计时；部分交卷明确标记，未生成题不计错。
- 保留程序校验、独立审核、查重、有限重试和真实用量计费；失败保留成果与释放对应预占，不降低质量门槛补齐题量。
- 覆盖冷启动、等待补题、答题卡、同步异常、审核阻塞、积分不足、小屏大字体、深色及减弱动画场景。

## 配套后端
本次 APK 需要配套的 AI learning 接口。部署当前发布分支的后端与 Web 后重启原服务，保留现有 DATA_DIR；新表会自动建立，不清空学习数据。
核对环境变量 MOBILE_LATEST_VERSION、MOBILE_DOWNLOAD_URL、MOBILE_RELEASE_NOTES 是否覆盖默认发布信息。
推送源码和上传 APK 不等于服务器部署、真实模型验题或手机实机验收。

设计图保存在 `docs/design/ai-generation-v1.0.11/`，是界面参考；其中数字为示意，运行界面使用真实数据。
