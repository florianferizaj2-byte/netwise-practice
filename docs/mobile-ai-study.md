# App 端 AI 精炼

入口位于 VIP 页当前套餐下方，进入独立的学习页面。沿用现有 `/api/study/...` 服务；Web 与 App 共用已发布课程、预留答案、学习进度和会员校验。

## 设计与交互

采用 frontend-design 的讲义式阅读方向，围绕真实知识点安排层次：一句核心说明、拆开的要点、具体例子、易错点，读完再练。使用系统中文字体，正文 18px / 31px，阅读宽度上限 760px，手机边距 20px。主题与 iOS 视觉适配复用现有 `useThemedStyles`、`iosStyles`，保持与 App 一致。主色强调关键内容和操作，避免额外的营销背景、装饰图和自动播放动效。

课程目录可以搜索知识点、按章节筛选，显示已读和已掌握状态；OSI 七层模型按七个小节呈现。学习与填空使用两个明确分区，“问老师”以可收起的底部答疑区打开，提供换个说法、例子、当前题目提示及自由提问。横屏或较矮视口把提问框与发送按钮并排，保留回复的阅读空间。输入区适配键盘，按钮有明确的可访问名称，触控高度至少 44px。

## 判分与恢复

- 每空的答案在发布内容包中预先保存，提交前不下发给客户端。
- 填写与预留答案逐字一致，该空直接满分；全部一致则整题直接满分，完全不调用 AI。
- 有出入的空交给 AI 依据答案、别名、类型、单位、容差及已审核材料复核。一致的空不能被 AI 改分。AI 不可用或无法确认时保留作答并允许重试；逐空展示成绩、依据及解析。
- 作答及提问重试沿用同一请求 ID，避免成功响应丢失后重复计分或重复消耗。
- 切换精讲/练习、导航页或返回 VIP，会保留当前未提交的填写。服务器保存已提交作答与学习进度；App 本地仅保存账号与证书对应的课程 ID 和分区，不持久化课程正文、答案草稿或私人答疑。
- 会员到期或接口拒绝访问时收起课程及答疑。隐藏页面停止目录和判分轮询；重新进入时同步权益与目录。Android 返回键先回目录，再回 VIP。

当前服务端已开放网络工程师课程。四川专升本计算机等其他目标显示课程准备状态，可切换目标或继续对应题库练习；目录不会展示虚构的课程。

## 验证

`npm run test:e2e:mobile-study` 使用隔离数据库、真实学习接口和模拟 AI，在 Chromium 与 WebKit 的 375px 手机视口检查 VIP 入口、课程、横屏答疑、失败重试、逐空评分、反馈、填写保留、刷新后进度恢复、会员失效与证书切换。截图输出到 `test-output/mobile-study`。

服务端测试另检查完全一致时 AI 不可用仍可直接满分、别名/空格/数值等差异确实调用 AI，以及 AI 不能改动已经命中的空。`npm run verify` 已接入新流程；Android、iOS 与 Web 的原生资源导出可通过 Expo 另行验证。模拟测试验证接口与状态处理，不代替真实模型判分质量的人工验收。
