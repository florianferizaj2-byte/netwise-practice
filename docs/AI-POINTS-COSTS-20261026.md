## 扣分公式

- 100 积分面值 = 1 元；维持既有 75% 服务加价口径，不做未获批准的提价。
- `上游成本 = 非缓存输入 Token × 输入价 + 缓存输入 Token × 缓存价 + 输出 Token × 输出价`（费率按百万 Token 折算）。
- 每个调用用整数微元核算；**扣除积分 = 实际模型成本（元）× 400**，任务聚合后向上取到 0.001 积分。
- Flash 每 1000 Token 对应积分：高峰输入 0.800、输出 3.200、缓存 0.016；空闲输入 0.400、输出 1.600、缓存 0.008。
- “实际成本”在自动结算中指上游返回的 Token 用量乘已确认费率，并非已核验供应商现金账单；现金账单差异需管理员对账。缺失可靠用量时不视为零成本，退回用户积分并暂停该渠道待核对。
