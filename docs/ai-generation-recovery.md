# AI 生成缺字段与旧任务恢复修复

## 修复范围
- 生成提示明确列出 question、options、answer、analysis 等必填字段及完整 JSON 结构。
- 对 question_text、questionText 等字符串题干别名和单一明确嵌套做无损映射；真正缺失的题干仍拒绝，绝不拼接参考题题干冒充新题。
- 程序校验、独立审核、查重与难度要求保持不变。结构错误以简短原因返回，不再把 Zod JSON 原文显示给用户。
- 已耗尽旧协议重试次数的暂停任务，可在修复后手动恢复一次有界重试窗口；仅补未交付槽位，已交付题目、答案与结算不重做。
- 尝试编号继续递增，避免复用已退款账单的幂等键。当前协议仍有重试上限，不做无限付费重试。
- 生成异常暂停时，考试从持久化的故障事件时间起暂停计时，避免修复等待耗尽原考试时间；普通补题等待与断线计时规则不变。

## 拉取与生效
在现有发布分支 codex/v1.0.1-blue-web-backend 拉取代码：
```powershell
git pull --ff-only
npm ci
npm run test:ai-learning
npm run build
```
随后按现有部署方式重启后端进程；只刷新 App 或更新静态网页不会替换服务端生成器。

无需清库、删任务或重新创建题组。重新进入原来的生成记录，点击“恢复后续生成”。旧客户端可以直接读取新的 retryable 状态，本次不要求重装 APK。未交付题目的后续用量按原规则结算，失败按原规则退款；已完成题目不重复计费。

## 验证边界
回归包含第5题缺失题干后的修正、从第5题起更换字段名的30题完整交付，以及旧4/30任务恢复、答案保留、失败退款、账单键不重复与故障停表。
测试使用隔离的合成模型返回，不代表真实模型的题目质量证明。线上现有任务需拉取并重启后端后，由用户在原记录中恢复验证。
