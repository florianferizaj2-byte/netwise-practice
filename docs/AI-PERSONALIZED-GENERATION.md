# AI 个性化练习与考试

底栏「AI 生成」和考试页「AI 个性化」共用生成服务。普通题库考试保持原有接口和计分规则。

## 运行与验证

- 启动：`npm run dev`。
- 个性化机制及接口测试：`npm run test:ai-learning`。
- Android 风格页面与断网恢复验收：`npm run test:e2e:ai-learning`（使用隔离数据库与合成模型，不访问真实上游、不产生真实模型费用）。
- 类型检查：`npm run typecheck`。
- Web 与移动网页版：`npm run build`。

真实生成需要管理员配置可用的 AI 接口、有效价格和账号可用积分。读取画像和预览方案不调用模型。用户确认积分规则并创建任务后才开始消费。

## 数据与质量

画像只使用当前账号、当前证书可见客观题的作答。统计按不同题目最近一次作答去重，近期证据按实际作答时间排序。多次重复刷对同一题不能认定稳定掌握；缺少证书归属的旧共享题记录不猜测归属，也不删除原记录。

服务端先冻结知识范围、阶段与难度蓝图，再逐题调用现有生成与独立审核链路。样本不足的知识点先诊断，不直接生成高难题。继续执行 Schema、计算复核、精确与相似查重；没有通过质量关的候选不会交付。独立 AI 审核并不等于绝对正确，真实模型效果仍需抽检。

## 持久化与交付

- `ai_learning_jobs`：账号/证书/请求编号、冻结方案、作答版本与服务端计时。
- `ai_learning_slots`：不可变题号、已交付题目和有界重试次数。
- `ai_learning_events`：递增事件编号，用于断流后补收。
- 一个账号最多一个活跃生成任务。工作进程用租约与令牌防止迟到结果覆盖；崩溃后的租约到期后由可用进程继续缺题位置。
- 合格题目、交付事件和本题积分结算在同一事务提交。已成功交付题目保留并结算；失败题预扣按现有积分规则退回。
- 页面退出、订阅断开和手机断网不取消任务。只有明确停止生成或部分交卷才终止剩余部分。
- SSE 使用鉴权请求、心跳、事件游标与轮询补拉。反向代理需允许流式响应，不能强制缓冲或截断长连接。

## 主要接口

- `GET /api/ai-learning/profile`：当前证书学习画像。
- `POST /api/ai-learning/preview`：四种策略、题量、范围与积分用量示例。
- `POST /api/ai-learning/jobs`：带 UUID 请求编号、画像版本和积分规则确认的幂等建任务。
- `GET /api/ai-learning/jobs[/:id]`：账号/证书隔离的任务和进度。
- `GET /api/ai-learning/jobs/:id/events?after=<事件编号>`：可续接事件流。
- `POST .../:id/start|answers|submit|retry|cancel`：开始、版本化答案增量、交卷、恢复或停止。

首批通常 3 题可开考，已停止/受阻任务可就已有合格题部分作答。等待暂停只在服务端确认所有已就绪题均已作答且仍缺题时生效；断网本身不暂停计时。未生成题不计为错误，部分卷不作为完整模拟成绩。

答案默认不包含在题目交付事件中。交卷以服务端记录判分，再返回解析。到期后不能用晚到作答改写到期前答案；本机晚到草稿可单独归档后按服务器记录交卷。草稿只保存用户自己的选择，按账号、证书、任务隔离，不进入普通题库缓存。
