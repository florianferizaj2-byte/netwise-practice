# v0.4.8 部署核对

本次只准备代码和安装包，不自动操作物理服务器。部署前保留原 `.env` 和完整 `DATA_DIR`，包括账号、学习记录、会员、头像、上传内容和管理员公告；禁止清库刷新版本。

1. 使用包含本次更新的分支或发布标签，在原项目部署流程中安装依赖、运行 `npm run build` 并重启服务。完整发布包需要包含新 APK、服务端和 `dist/app/`，不能只替换静态首页。
2. `server/mobile-release.json` 已包含最新 0.4.8、最低 0.4.3 和 APK 校验值。建议清空旧 `MOBILE_*` 版本覆盖项，使用内置策略；旧 latest 为 0.4.6 的配置也不会再提高最低版本。
3. 核对 `/api/mobile/version?version=0.4.2`：最新 0.4.8、最低 0.4.3、`forceUpdate=true`。
4. 核对版本 0.4.3、0.4.5、0.4.7：`updateAvailable=true`、`forceUpdate=false`，登录与学习接口可用。0.4.8 应无更新提示。
5. 核对 `/downloads/kaojiang-v0.4.8.apk` 完整内容及 SHA-256，支持 Range 续传；`/app/version.json` 应为 0.4.8。
6. 真机安装 code 33，核对登录、学习记录、开屏与安装器；通过测试版策略核对“继续使用旧版本”和下次打开重新提醒。不要为测试修改面向所有用户的生产策略。

已安装旧包无法远程补充更新按钮，详见 [兼容限制](release-v0.4.8.md#旧客户端兼容限制)。发布 APK 和后台部署是两项独立工作。
