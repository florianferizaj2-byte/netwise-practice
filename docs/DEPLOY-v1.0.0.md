# v1.0.0 部署与手机验收

## 更新服务器

1. 停止原服务后备份现有项目、`.env`、整个 `DATA_DIR`，或使用 SQLite 一致性备份；特别保留数据库、用户头像和上传文件，以及原 `AI_MASTER_KEY`，更换会让旧 API Key 无法解密。
2. 将本次 `kaojiang-server-v1.0.0-*.tgz` 解压合并覆盖到原项目。更新包含已构建电脑官网和正式 APK，不需要在服务器重做 Android 构建。手机网页暂不做，本包不包含 `dist/app/`；保留服务器现有目录，不要删除整个 `dist`，不要使用带删除目标文件选项的同步。
3. 使用 Node.js 24 或以上，在原项目目录运行：

```sh
npm ci --omit=dev
```

保持原 `DATA_DIR`、端口、代理和域名配置。不要清库、不要用测试数据替换现有数据，也不改占用其他服务的端口。
积分迁移在启动时补表；如果希望先单独备份并校验原表不变，可以运行：

```sh
npm run points:migrate -- --data-dir /原来的数据目录 --backup-dir /你的备份目录
```

4. 用原来的宝塔、PM2 或服务配置重启。使用 PM2 时对原进程执行 `pm2 restart 原进程名 --update-env`；不要另开一个进程抢同一端口。
5. 确认反向代理将 `/api` 交给 Node，电脑官网使用本包的 `dist`，`/app/` 仍使用服务器原有手机网页文件；`/downloads/kaojiang-v1.0.0.apk` 必须能完整下载并支持 Range。APK 最低版本要求不会强迫浏览器安装 Android 包；手机网页专项兼容验收未执行。

旧的较低 `MOBILE_LATEST_VERSION` / `MOBILE_MINIMUM_VERSION` 不会把本包降回旧版；如配置过更高版本或自定义下载地址，应先核对这几个变量。
版本信息和 APK 必须一起更新，不能只换后端就强制用户下载一个不存在的安装包。

## 连接自检

```sh
npm run deploy:check -- --url https://aceexam.top
```

这会检查真实版本协议、配套路由声明、APK 文件头、文件大小和分段下载。
未提供登录会话时，会明确显示登录接口检查“未执行”，不把匿名 401 当作已接通。
如已取得 v1.0 手机登录返回的会话，可在当前终端设置 `ACEEXAM_SESSION_TOKEN` 后重跑：

```sh
npm run deploy:check -- --url https://aceexam.top --apk dist/downloads/kaojiang-v1.0.0.apk
```

有会话时额外检查钱包、AI 价目、记录、会员权益、账号安全、练习目录、考试目录和专项学习；不发起 AI 调用、不改用户数据。
会话是私密凭据，不写进文件、仓库或公开截图，检查完删除终端中的临时变量。

## AI 与积分配置

- 保留原作者 AI 配置或管理渠道，核对模型是否可用、费率是否确认且未过期。环境变量示例见 `.env.example`。
- 真实资金与积分账本由管理员核对。未记录资金时，待发放积分不应被伪装为可花余额；普通刷题仍可使用。
- 邮箱验证默认关闭；需要启用时先配置 SMTP，并运行 `npm run auth:mail:check`。不要把邮箱密码或模型 Key 放进 App。
- 本地检查不证明真实模型回答质量或外部购买完成；这些应使用自己的配置单独验收。

## 手机上最后检查

安装 `kaojiang-v1.0.0.apk` 后核对：

1. 从旧正式版覆盖安装，账号与已保存学习记录仍可恢复。
2. 登录后首页有真实题量；练习答题、错题加入/移除、收藏和考试保存/交卷正常。
3. “我的”、会员详情、长文本和大字号不截断；会员详情的系统返回键可返回。
4. 钱包和权益同步，签到不重复发放；兑换码有效性由后端判断；价格与积分以实际配置核对。
5. 断网时有明确提示，恢复网络后可重新连接；退出或切换账号不显示前一账号的数据。
6. 原生照片权限、安装更新、专项学习入口和系统权限按 Android 实际提示操作。

如显示“服务端尚未完成 v1.0 升级”，先核对 API 是否仍指向旧进程、旧目录或代理缓存，而不是反复安装 APK。
