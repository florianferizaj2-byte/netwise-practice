# 考匠 v1.0.0

Android 包名 `com.kaojiang.app`，版本 1.0.0，versionCode 33，沿用正式签名，兼容原正式签名安装包覆盖升级。

## 本版改进

- 接入同一套前后端积分协议：钱包、AI 费用、使用记录、单次扣费与退款回执；套餐展示读取后端数据。
- 打通登录、邮箱安全、兑换、签到、普通练习、错题、考试和专项学习链路。
- 修复启动恢复账号时误取消公共版本检查的问题；服务端未升级或网络中断时显示明确提示并可重新连接，不把未知余额显示成零。
- 保留最新中文字体、字号层次、圆角与页面间距，修复“我的”底部和会员页面排版；会员详情支持 Android 返回操作。
- 安装更新前检查 HTTP 状态、文件类型、大小及下载完整性。MD5 仅用于损坏检测，真实性依赖 HTTPS 和 Android 正式签名验证。
- 新增部署自检；更新包必须通过完整发行验收和源码/构建一致性检查后才可生成。

## 边界

本次发行范围为 Android APK、配套后端和电脑官网的接口兼容。手机网页、iPhone 网页暂不调整、不验收、不随更新包发布；部署时保留服务器现有 `/app/` 目录。

本版不合入本地未审核的题库增删；普通题库继续使用既有发布内容。
AI 是否可调用取决于服务器的模型、有效费率与资金配置；本地验收不消费真实模型、不伪造真实资金或用户积分。
线上部署由站点维护者执行；真实手机的安装、系统权限、安装器和原生功能需在部署后验收，不能用浏览器检查替代。

安装包、校验文件、服务端更新包及部署说明一起交付。完整验收结果以本次生成的发行记录为准。
