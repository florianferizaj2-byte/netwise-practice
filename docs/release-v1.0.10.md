# 考匠 v1.0.10

Android `com.kaojiang.app`，版本 `1.0.10` / versionCode `43`。沿用正式签名，保留账号、学习记录和已下载语音包。

## 更新

- 修复首页“继续今日学习”和顺序刷题从头开始。普通范围入口自动读取真实断点，退出、重启后继续上次未完成题；当前选项和未提交内容一并保存。
- 顺序、随机及章节/分类/考点分别保存；每日学习、普通练习、复习互不覆盖。章节继续练习优先真实断点，不再只看完成百分比。
- 正常刷题排除已答对题；离线即时判分先记本机状态，服务器回执确认或校正。已确认答对题不会因为主动复习答错而重新混入新题。
- 首页和练习目录新增“复习已答题”，可单独回顾、重新作答。
- 配套后端同时支持顺序和随机排除历史答对题，返回账号隔离的已答/掌握状态；未提交的考试占位记录不算已答。
- 旧服务器仍按本机真实记录过滤；跨设备及旧版历史答对状态的完整同步需要部署本次后端。无需清空数据库或 App 数据。
- 包含此前 v1.0.9 的错题删除或保留、右滑跳过、语音包快捷入口、AI 出题、安全区及模拟定位学习优化。

## 部署

更新现有分支的后端和 Web 构建后重启服务，保留现有 DATA_DIR。检查环境变量 MOBILE_LATEST_VERSION、MOBILE_DOWNLOAD_URL、MOBILE_RELEASE_NOTES 是否覆盖默认发布配置，并同步为 1.0.10 和新下载地址。手机端通过新 APK 覆盖安装。

源码验证、APK 构建、GitHub 上传、线上部署与真机验收分别记录；本次不自动操作生产服务器或安装手机。
