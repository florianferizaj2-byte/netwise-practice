# 考匠 v0.4.3：虚拟定位学习

2026-10-13。本地安装包新增学习入口和必须同意的用途协议，不变更服务器题库或部署配置。

## 功能

- 入口：“练习” → 普通顺序或随机练习章节目录底部 → “虚拟定位学习”。
- 每次进入弹出“学习用途与免责协议”，明确仅供学习使用，严禁用于校园跑作弊。不同意返回，同意后才可开始，不永久保存同意状态。
- 简洁蓝白原生界面，仅“开始”“结束”两个主按钮及文字教程入口，没有地图或卡密。
- 原样内置提供的路线：24 个 WGS84 点，12 km/h，顺序运行一次，到终点自动结束。
- 教程覆盖选择“考匠”为模拟位置应用、精确位置权限、系统定位、通知及后台电池设置；通知可以结束运行。
