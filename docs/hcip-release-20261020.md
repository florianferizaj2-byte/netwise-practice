# HCIP-Datacom 首批 Web 接入（2026-10-20）

本次把 HCIP-Datacom 两个考试方向接入 Web 证书目录、备考指南、章节练习和模拟组卷。考试章节与权重按[华为 ICT 职业认证手册](https://e.huawei.com/marketingcloud/pep/asset/20000001/Material/2e95f85dc2d84ccab7d3d68f37622339/M1T1A669N723556651875254273/_202204_Huawei%20Career%20Certification%20Brochure%20in%202022.pdf)中的 V1.0 考纲核对；题目均为本站原创仿真练习，不是官方真题。官方手册列出 H12-821 13 个章节和 H12-831 8 个章节及其权重。

| Web 证书 | 考试代码 | 当前已审题量 | 本站配题目标 | 已覆盖知识点 |
| --- | --- | ---: | ---: | ---: |
| HCIP-Datacom 核心 | H12-821 | 670 道 | 900 道 | 43 / 51 |
| HCIP-Datacom 高级路由交换 | H12-831 | 320 道 | 900 道 | 21 / 36 |

每个大纲章节都有专属章节图标，使用仓库已有插画和动效组件。证书选择页、章节页使用相同目录映射；插画生成检查会在证书目录变化但缺少映射时失败。

本站的 900 道目标按官方章节权重每 1% 配 9 题计算，用于控制练习内容比例；它不是华为公布的考试题量。当前题库虽然已覆盖全部章节，但部分章节和知识点的题量仍不足，复习和组卷按现有题量工作，后续需要补齐覆盖缺口。官方考纲没有公布题型构成，因此当前示范库只包含单项选择题。

## 审核范围

当前包只收录通过现行内容流水线的批次，共 21 批、990 道：核心方向的初始 20 题及 13 批扩题共 670 题；高级方向的初始 20 题及 6 批扩题共 320 题。每题保留逐题来源和复核摘要。

早期整理的 163 道题（核心方向 82 道、高级方向 81 道）仍在原工作区材料中，但当前流水线判定其复核摘要过期，本次没有接入。后续扩题批次目前缺少必需的作者上下文，也未接入。没有通过门槛的内容不会混入 Web 发布目录。
