# 考匠电脑端设计

## 范围

仅在宽度至少 900px、支持鼠标悬停和精细指针的电脑浏览器启用。移动设备、Apple 移动网页、`/app/`、小程序与原有窄屏网页保留原界面。新增样式采用独立的桌面根节点和 `desk-` 类名前缀。

## 视觉方向

考匠的核心是把知识练扎实。首屏以大字号中文和可以直接作答的 5 道免登录体验题建立印象，保留考匠印章标识。练习、讲解、复习与模拟考试构成清晰的学习路径，不使用虚构学员数量、通过率或评价。

- 墨绿 `#153E35`：标题与品牌底色。
- 松绿 `#24715C`：主要操作和进度。
- 浅玉 `#EAF2EE`：次级背景。
- 纸白 `#FFFFFF`：主要阅读区域。
- 雾白 `#F6F8F7`：工作台底色。
- 灰绿 `#697B74`：辅助说明。
- 字体：现有 Noto Sans SC，回退 Microsoft YaHei；数字采用系统无衬线字体。中文标题使用紧凑字距与清晰行距。

## 布局

品牌页：导航 → 左侧主张与入口 / 右侧交互题目 → 学习路径 → 完整功能目录 → 证书选择 → 多端入口。

工作台：固定侧栏 / 顶部搜索与多端下载 / 继续练习和到期错题 / 章节进度。主导航保留学习总览、章节练习、错题本和模拟考试；其他学习工具折叠，会员和兑换保留在账号菜单，证书直接在侧栏切换。学习计划和薄弱点按需展开。

章节页使用左侧章节目录、右侧知识点列表，来源说明折叠。练习页首先呈现题干、选项和作答按钮，答题卡移到侧栏，每页最多显示 40 个题号。考试设置采用范围与考试摘要双栏，开始按钮在摘要中保持可见。无错题或无搜索结果时提供下一步入口。

练习位置、已提交答案和未提交输入按账号与证书保存在当前浏览器；退出、刷新和浏览器返回可继续上次练习。题库移除的题目会跳过，内容变更的题目重新作答。该进度只属于当前浏览器，已提交的学习记录仍通过服务端同步。

多端展示与下载使用独立的 `/#downloads` 页面，无需登录。电脑网页、Android App、iPhone / iPad 网页分别展示；安卓版本与安装包地址来自 `/api/mobile/version`，二维码在浏览器本地生成。账号菜单、顶部工具栏和品牌首页均可进入。苹果浏览器访问这个页面时不自动跳走。

首屏的题目演示是视觉重点。其余区域使用留白、分组与克制的边框建立层级，避免将所有内容做成相同卡片。

## 功能连接

使用原有登录、注册、证书选择接口；登录后保留用户选择的目标页面。章节、错题、AI 训练、共享题库、社区、掌握度、模拟考试、会员、兑换、设置及管理员功能继续使用现有业务组件。新增功能搜索支持快捷键 Ctrl/Cmd + K。学习统计与进度直接取自现有接口，安卓下载地址取自移动端版本接口。

## 免登录体验

- 选用现有网络工程师原创题库中的 5 道单选题（practice-1、2、5、7、10）。匿名访客可以作答、查看基础解析、请求 AI 详细解析及错题分析。
- 服务端保存首次作答与体验进度。匿名 Cookie 为 HttpOnly，30 天有效；刷新页面继续同一组题。体验记录不写入正式账号的作答、错题或会员额度。
- 使用现有作者 AI 连接，浏览器没有密钥，也不能提交自定义提示词或指定其他题目。
- 与正式用户共用 `ai_question_content`：详细解析复用原有 `explanation:详细讲解` 缓存；错因复用 `mistake-analysis` 缓存。缓存键仍包含题目修订指纹，错因还包括所选错误答案。访客生成的结果也可被正式用户复用。
- 命中共享缓存时直接读取，不调用上游 API，也不消耗体验 AI 请求限额。同一进程的生成任务继续使用现有 AI 并发控制，重复点击不会并行生成。
- `.env.example` 中提供每日来源与全站限额；用于限制无缓存的新请求。无需在客户端配置服务地址或密钥。

## 部署

1. 更新前备份服务器的 `.env`、数据库及用户上传文件，保留原有作者服务配置。
2. 同步完整源码及依赖清单，包含桌面品牌页、学习工作台、多端下载页、练习进度模块及配套样式；保留 `server/guest-trial.js`、`server/ai.js`、`server/index.js` 和 `public/mobile-entry.js` 的配套变更。
3. 安装根目录与 `mobile` 的依赖，运行 `npm run build`，发布完整 `dist/`（含 `dist/app/`）并重启 Node 服务。只更新静态网页无法启用免登录体验接口。
4. 在电脑浏览器检查首页、5 道体验题、AI 解析、登录注册、证书选择和学习总览。手机浏览器另行检查 `/app/`。

本地预览运行 `npm run dev`，默认访问 `http://127.0.0.1:5173/`。源码上传 GitHub 与线上服务器部署是两个独立步骤。
