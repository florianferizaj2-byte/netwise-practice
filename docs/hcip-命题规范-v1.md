# HCIP 补题命题规范（v1，2026-10-28）

依据 `docs/hcip-真题样本-20261028.md` 的真题结构比对制定。目标是让补题在**题型、选项形态、干扰项写法**上与真题一致，同时消除原库的统计缺陷。

## 一、题型配比

| 题型 | 占比 | 说明 |
|---|---|---|
| 单选 | 70% | 4 选项，1 个正确答案 |
| 多选 | 20% | 4 选项，2–4 个正确答案，禁止"全选"超过 30% |
| 判断 | 10% | 固定 2 选项（正确/错误），错误陈述占 40%–50% |

真题样本中判断题与多选题占比很高（题库 1178 题中判断题约 1/3、多选题约 1/4），原库 100% 单选与真题差距最大，必须补齐。

## 二、选项写法（核心）

1. **长度**：每个选项 6–30 字；四项极差 ≤ 12 字；最长/最短 ≤ 2.6。
2. **平行结构**：四个选项必须是同一层级的表达——都是名词短语、都是数值、都是命令、都是动作。
3. **禁止"一句完整解释 + 三句荒谬短句"**：这是原库 69% 选最长命中率的根因。
4. **干扰项必须是"同层概念互换"或"参数改值"**：
   - 概念互换：把 Trust 换成 DMZ、把 Local_Pref 换成 MED、把 Swap 换成 Push
   - 参数改值：把 85 改成 100、把 60 秒改成 180 秒、把 646 改成 179
   - 禁止："只提供物理接口，不参与任何协议计算"这类一眼假的极端陈述
5. **禁止**："以上都对 / 以上都不对 / 无法判断"。

## 三、答案位置

- 不设配额，整批随机；相邻两题答案相同的比例必须落在 20%–28%。
- 正确项为"唯一最长"的比例 ≤ 35%（原库 65%–70%）。
- 多选答案的字母组合不得集中在 ABCD（全选占比 ≤ 30%）。

## 四、题干

- 30–90 字，一句话说清条件与设问。
- 20% 为场景题：给配置片段、拓扑角色或现象，问结果。
- 不引用图片；"如图所示"一律改写为文字描述。
- 否定式设问（"错误的是"）占比 ≤ 15%，避免与正向设问混淆。

## 五、解析

- 60–160 字。
- 结构：先给正确项依据（协议规范/命令行为），再逐项指出错误项的错点。
- 不写"暂无解析"；不复制第三方解析原文。
- 计算题必须写出算式。

## 六、难度

按认知层次标注，不按题干长度：

| 难度 | 判据 |
|---|---|
| easy | 单一事实识记（缺省值、端口号、术语定义） |
| medium | 需要理解机制或做一步推理（选举过程、报文流程、属性比较） |
| hard | 多步推理、多条件综合或需要计算（路由复算、故障定位、方案取舍） |

## 七、知识点与来源

- 每题必须绑定 `taxonomy` 中已存在的知识点编码，`chapter / knowledgeSection / knowledgePoint` 三者由编码反查，不允许手填。
- `provenance.locator` 记录编码与依据范围；`reviewStatus` 标注复核状态。
- 不得复制第三方题库正文；题干与选项须独立撰写。

## 八、验收门槛

| 指标 | 门槛 |
|---|---|
| 知识点覆盖 | 100%（每个知识点 ≥ 1 题，目标值 ≥ 章节目标/知识点数） |
| 章节题量 | ≥ 目标题量的 90% |
| 「选最长」命中率 | ≤ 40%（原库 69%/73%） |
| 相邻答案重复率 | 20%–28% |
| 正确项唯一最长占比 | ≤ 35% |
| 题干完全重复 | 0 |
| 选项集合完全重复 | ≤ 0.5% |
