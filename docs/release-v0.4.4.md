# 考匠 v0.4.4：悬浮控制与路线进度

2026-10-14。本地版本在已有“虚拟定位学习”入口中加入悬浮控制。

## 操作

1. “练习” → 章节列表底部 → “虚拟定位学习”，同意仅供学习、禁止校园跑作弊的协议。
2. 在“使用教程”中开启“显示悬浮按钮”，按提示允许显示在其他应用上层和精确位置权限。开启控制本身不会开始模拟定位。
3. 可以切换其他应用；悬浮窗只有一个按钮，点“开始”并确认协议后，按钮显示“结束 · 0%”，随路线进度更新。首页和通知同步显示百分比。
4. 点“结束”停止模拟定位，按钮保留并变回“开始”。按原 24 点、12 km/h、单次路线到终点自动完成时，进度为 100%；再次开始从起点重跑。
5. 拖动可移动，长按关闭。关闭悬浮窗时运行中的路线继续，可从首页或通知结束；空闲时关闭会结束本模块前台服务。

悬浮窗默认关闭，必须显式授权。空闲时保留控制和通知，不输出模拟位置、不持有运行唤醒锁；系统强停进程后不会自动重跑。
