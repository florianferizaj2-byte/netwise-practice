- `server/question-banks/veterinary-practitioner/reports/context-withdrawals-20261021.json`：运行时消费的明确下架清单，由 manifest 的 `questionWithdrawalsPath` 引用。

## 旧数据库同步

仅从 JSON 移除题目不会让已经初始化的数据库停止提供它。服务器启动时会读取明确下架清单，使用既有 `admin_question_visibility` 隐藏相应题号，并在练习列表、直接取题、作答、收藏练习、错题、队列和新组卷中排除这些题。包含已下架题的未完成试卷返回 `EXAM_QUESTION_WITHDRAWN`，要求重新组卷；已交卷历史仍可查看。

原题行、答题、收藏、试卷和删除标记均保留，不清空 `DATA_DIR`。下架题不能通过普通的“上架”开关绕过内容清单，需先完成材料审核并更新题库发布内容。

如只需给本地已有库应用本次维护，而不运行其他启动迁移，可执行：

```powershell
node scripts/sync-veterinary-context.mjs --data-dir data
```

该命令要求数据库已存在，先在 `tmp/veterinary-context-repair-20261021/database-backups/` 生成 SQLite 备份，再在同一事务内更新已审核的材料和下架状态。旧库如缺少下架状态表，只创建与正常启动一致的 `admin_question_visibility`，不运行其他启动迁移。它核对原题、选项、答案和解析摘要，拒绝覆盖范围外的改动，并核对学习记录数量不变。缺失题不会凭此命令新增。已运行的服务器需要重启以重新读取内存题库。
