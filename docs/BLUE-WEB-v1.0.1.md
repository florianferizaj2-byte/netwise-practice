# 蓝色 Web 与 v1.0.1 后端

蓝色新版 Web 已合入本分支，包含首页、证书与章节、练习/错题/收藏、学习计划、模拟考试、互动精讲、会员和资料设置。后端沿用正式 v1.0.1 接口、账号隔离与每日专项 10 题规则；APK 文件未修改。恢复 GitHub 主分支已发布的 C 语言、HCIP 核心、HCIP 高级与四川强化题，完整保留 8 类证书；未重新编写题目。

## 使用源码部署

在独立构建目录检出 `codex/v1.0.1-blue-web-backend` 分支，使用 Node.js 24 或以上，安装完整依赖后运行。不要直接在正在提供服务的旧目录运行构建，Vite 会清理本地输出目录：

```sh
npm ci
npm run build
npm run verify:web-blue
```

本分支 `release-target.json` 仍排除手机网页构建；电脑 Web 使用新的蓝色页面。保留现有 `.env`、`DATA_DIR`、`AI_MASTER_KEY`、上传文件及已有 `dist/app/`，不得清库。停止原服务并备份后，把独立目录生成的 `dist` 和后端源码合并覆盖到原项目，保留服务器已有的 `dist/app/`；不要删除整个 `dist`，不要使用带删除目标文件选项的同步。然后用原来的进程管理方式重启。

本次 GitHub 源码更新不修改上次桌面的后端压缩包；该旧压缩包仍是旧 Web。需要蓝色界面时，从本分支重新构建，不要用旧包覆盖 `dist`。

线上部署、真实模型调用与手机实机验收未执行。部署后的接口自检：

```sh
npm run deploy:check -- --url https://aceexam.top
```
