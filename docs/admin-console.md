# 考匠 Web 管理工作台

## 入口与边界

管理员登录后进入 `#admin/overview`。原 `#admin` 打开总览，`#study-admin` 打开教学管理。使用独立管理导航；顶部证书筛选不改变管理员自己的备考方向。

运行 `npm run preview:admin` 后打开 `http://127.0.0.3:4179/preview/start`，可使用独立本地演示账号。演示数据保存在 `outputs/admin-console-preview`，不使用真实账号数据库，AI 提供者拒绝外部调用。原学习者预览账号不增加管理员权限。

本轮沿用 `isAdmin`，没有增加团队角色。所有管理请求在服务端检查权限，普通账号不能靠输入地址进入。正式 App 使用的用户、会员、公告接口保留。

## 功能组织与扩展

- 工作台：总览、待办和任务中心。
- 内容：证书三级目录、题库筛选与完整预览、修订草稿、批量导出、下架恢复、隔离批次导入、质量检查。
- 教学：现有课程生成、审核、发布、停用、判分申诉；静态互动课覆盖和受控内容预览。
- 用户运营：账号资料及权益、封禁解封、会员兑换码、公告、题目反馈状态及关联修订。
- 系统：有效 AI 配置来源、加密配置、调用与成本、审计检索、运行信息及内容摘要。

前端模块注册在 `src/features/admin/registry.jsx`。每个模块声明路由、分组、图标、说明、是否使用证书范围和懒加载组件；容器与通用表格、分页、弹窗、资源加载分开。增加模块时注册入口并实现独立页面即可。

新接口位于 `/api/admin/console/*`，包括 `overview`、`catalog`、`questions`、`visibility`、`documents`、`jobs`、`quality/scan`、`generation`、`feedback`、`usage`、`audit`、`teaching`、`config`、`system`。用户与公告是现有服务的兼容别名。

## 内容修改、审核和发布

### 两类内容分开

内置题库仍保存在 `server/question-banks/`，随代码发布。网页修改保存为持久草稿，不直接覆写当前正式题目。管理员 AI 生成也保存为待审批次，不直接写进共享题库。用户自己的私有 AI 题不进入全局管理题库搜索和导出。

静态互动课程沿用现有协议、渲染器和代码发布。数据库中的精讲与填空课程沿用现有生成、审核和发布规则。

### 批次文件

支持导入现有的 `batch.json`、`questions.json`、`sources.json`、`provenance.json`、`reviews.json`、`blueprint.json`，以及可选的 `manifest.proposed.json`、`guide.json`。也可读入合并的批次对象或本后台的发布包。每批最多 50 题、草稿内容最多 3MB。

编辑器维护题干、选项、答案、解析、三级分类和难度；图片、共用题干和完整字段可用受控 JSON 编辑。目录提供章节、二级分类、知识点、编码和范围的表单。JSON 修改需先应用，再保存；未应用或未保存内容会提示。

网页和命令行共用 `server/content-quality/` 的合同和检查逻辑，原 skill 路径是兼容导出。独立复核缺失、与作者相同、答案不一致、摘要过期、来源或范围不合要求，以及硬重复都会阻止导出。页面点击不能代替真实独立复核过程，也不代表专家认证。

### 题目纠错

修订使用新题号，保留原题。`provenance.replacement` 记录原题 ID、证书、原题内容摘要和具体纠错依据，并被纳入独立复核摘要。必须有实质内容修改，不能仅换题号；其他题目的重复检查继续执行。跨证书共用原题的替换需要专项迁移，首期不能从单证书批次直接放行。

发布包接入代码后，可信内置来源中的替换关系会在启动时核对原题摘要并下架原题，不删除历史。人工下架/恢复同样保留题目、答题、收藏和考试记录。新练习和新试卷使用可用题目，原有考试仍能读取旧题完成交卷。

### 导出交接包

“检查并导出发布包”重新执行当前检查，生成 JSON 文件，包含原始审核输入 `auditInputs`、加载器可读题目、拟添加 bank、来源复核记录、检查报告、素材路径和接入说明。

解包到新的隔离目录：

```powershell
node scripts/unpack-admin-content.mjs --file "下载的发布包.json" --out tmp/admin-content-import
node .agents/skills/kaojiang-content-pipeline/scripts/pipeline.mjs check --batch tmp/admin-content-import
node .agents/skills/kaojiang-content-pipeline/scripts/pipeline.mjs prepare --batch tmp/admin-content-import
```

按 `prepared/integration.json` 核对并接入源码，再运行现有 `verify`、`exam-smoke` 和相应浏览器验收。解包器只接受 `tmp/` 或 `outputs/` 的新目录，不覆盖正式题库。

“下载隔离草稿”和“导出核对”不是已审核发布包。“运行库已匹配”依据当前服务实际加载的题目核对，不证明另一台生产服务器已更新。

新证书必须补齐真实范围来源、三级目录、指南及有效题目。仅有目录草稿不会生成可发布空证书。图片需要已存在并经审核的本地素材；交接时按素材清单同步。

## 数据与操作恢复

- 增量表保存草稿、任务、反馈处理、下架状态及幂等回执，位于当前 `DATA_DIR` 的 SQLite 中。
- 草稿、用户资料、反馈和 AI 配置检查读取版本，冲突返回 409；下架先预览，并使用请求编号恢复丢失的成功回执。
- 扫描和质量检查在工作线程中执行，可取消。生成执行中等待上游结束；失败重试由管理员明确触发。重启中断任务不会自动再次消费 AI。
- 密钥只在服务端加密保存，不在读取、审计或导出中返回。连接测试显式触发，使用实际生效的配置来源并计入用量。
- 费用显示有依据的已知金额及未知次数；未知不能显示为零成本。
- 公告为纯文本。Web 首页和 App 读取同一公告源；Web 打开首页时读取，页面可见时每分钟更新，临时失败保留上次成功内容。
