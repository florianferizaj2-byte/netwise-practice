# 考匠 v1.0.1

Android 包名 `com.kaojiang.app`，版本 1.0.1，versionCode 34，沿用正式签名。

- AI 操作改为简短底部确认，费用示例、退款规则与完整价目收入「费用说明」入口，保留明确确认/取消及服务端余额校验。
- 选项字母填满圆形定位框并居中，支持系统字号；答案解析卡增加内边距，AI 操作改为双列加整行，在窄屏和大字号下改为单列。
- 原生弹窗有独立安全区，专项练习的导航和按钮避开状态栏、挖孔与手势区。
- 每日专项学习由30题改为10题；仍保留每题阅读1秒、错题阅读3秒、账号与证书隔离和完整材料组选择。旧30题轮次保留已完成进度；已完成10题及以上直接满足当天资格，不删除原答题记录。
- 「我的」会员卡使用中性底色、集中展示积分数字，操作入口收紧为同一行。

本次不发布或覆盖手机网页 `/app/`，不修改内置题库。10题规则需要同时更新配套后端；客户端展示服务端实际返回的题数，不伪装部署成功。

本地自动化、正式签名打包、GitHub推送、线上部署、手机实机和真实AI验收分别报告；不把浏览器渲染检查当作实机验收。
