# 考匠 v1.0.4

Android `com.kaojiang.app`，版本 `1.0.4` / versionCode `37`。此安装包本地构建后随本轮源码提交到 GitHub 发布分支；未另建 v1.0.4 Release，不替换 v1.0.3 已发布文件。

## 更新

- 新增答对提示音与轻短震动，在“我的 → 设置 → 答对反馈”分别开关。
- 三种音色、四档音量和三档轻短震动时长，支持体验当前设置；偏好在本机持久保存。
- 普通练习与本次专项练习答对触发一次；答错、回看、重复同步和考试不触发。后台或离开当前题后取消迟到的音效。
- 音效离线预载，不等待网络；本次声音和震动无需新增后端接口。
