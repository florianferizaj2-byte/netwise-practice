# 2026-10-19 · Web 学习空间与管理后台大更新

这次更新将蓝色 Web 学习空间与独立管理工作台放进同一套产品和验收流程。学习者从选证书、练习到错题复习、考试和计划都有真实数据；管理员可以在网页完成内容整理、持久草稿、审核交接、用户运营与系统检查。

## 发布范围

用户确认本次提交 **Web 学习区与新版后台**。以原有蓝色 Web 候选提交 `4cbbd3f` 为基线，加入本次后台改动；沿用已发布 App 0.4.6 的源码与元数据，保留此前已提交的题库。

不合入共享工作区中正在进行的 App 0.4.7、兽医题库整理、额外 C 语言补题、HCIP 新证书和四川专升本补题。本机预览可以看到这些内容，不能据此声称它们已经进入本次提交。对内容的独立审核与发布继续分批执行。

本次不新建 APK 版本，不创建移动端发布标签，也不代表生产网站已经部署。

## 学习空间

- 蓝白公开首页、登录、学习总览、章节、刷题、错题、考试、收藏、计划、会员、证书选择与设置统一视觉；保留窄屏、深色、字号与减弱动画。
- 章节大小插画与实际所学章节关联；W / X / P 等有限动效可通过悬停和键盘聚焦触发。兽医专项保持适合病例与配伍题的流程。
- 练习支持三级范围、题库来源、顺序随机、题量和未练范围；错题入口先进入总览，收藏支持检索和复习。
- 知识点组卷、考试暂存、离线恢复、跨设备冲突、交卷评分与成绩检索复用可信服务端。
- 计划按真实任务推进，学习提醒时间随账号保存，在网页可见时触发。
- 分步精讲使用审核内容与固定组件，标准答案留在服务端，按不同错误进入对应补课。首发为 39 节完整课及 VLAN 部分示范，其余 107 节保留原精讲。

## 15 个后台模块

总览工作台、任务中心、证书与目录、题库管理、导入与审核、质量检查、AI 教学管理、用户管理、会员与兑换码、公告管理、用户反馈、AI 服务配置、用量与成本、操作审计、运行状态。

后台采用独立分组侧栏、面包屑、功能搜索和返回学习空间入口。模块按需加载，表格、分页、弹窗、状态和操作反馈共用组件；新增功能通过注册表接入。使用 `#admin/...` 子路由，保留旧入口，服务端继续按现有管理员身份授权。

## 管理数据与内容发布

- 内置题编辑保存为持久草稿，管理员 AI 扩题也先进入待审批次，不直接发布。
- 网页和命令行共用内容协议与质量检查。缺来源、独立复核、有效摘要，或命中硬重复时不能导出可发布内容。
- 发布包含原始审核输入、加载器题目、清单片段、报告和接入说明。解包器只写新的隔离目录，代码接入后仍须核对真实加载结果。
- 修订题绑定原题内容摘要并使用新 ID。服务启动同步会保留原题与学习历史；只改解析的修订也能正确升级，不产生指纹冲突。
- 下架与恢复先预览影响，不删除答题、收藏和已有考试。用户资料、配置、反馈和草稿检查版本；重复操作保留幂等回执。
- 任务支持进度、取消、失败重试和重启恢复说明。中断后不会自动重试收费生成；测试连接也需管理员明确操作。
- 用量来自实际记录；有价格依据时统计估算成本，缺价格的调用单列未知，不记成零费用。
- 公告通过现有公共接口同步 Web 与 App。App 已使用的用户、会员和公告接口保留。

## 升级与回退

1. 备份 `.env` 与完整 `DATA_DIR`，确认 SQLite 备份一致；保留主密钥、公告、头像、上传文件及原有备份。
2. 获取本次合并请求中实际核对的提交。先在预发布环境安装根目录及 `mobile` 依赖，运行完整验收。
3. 运行 `npm run build`，同步完整 `dist/`（包含 `dist/app/`）和服务端代码，用原服务管理方式重启。
4. 服务会增量创建后台草稿、任务、反馈、下架和幂等记录表。无需清库，不覆盖题库外的个人记录。
5. 分别用普通账号和管理员核对权限、登录、练习、错题、考试恢复、草稿、公告与会员接口；真实 AI 配置测试及账单核对单独记录。

回退时恢复已备份的代码和构建，保留数据目录和新增表。不要删除题目记录或清空数据库，不把本地预览数据库复制到生产。
