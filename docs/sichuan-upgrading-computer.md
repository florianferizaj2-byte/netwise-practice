# 四川专升本 · 计算机基础

“四川省专升本 · 计算机基础”与现有证书使用同一套考试目录。新用户可以直接选择，已有用户可以在备考目标中切换；电脑网页、移动网页、Android 源码和小程序共用服务端模块。

## 考点与学习安排

范围采用四川省教育厅《计算机基础》考试要求，2026 年考试实施规定确认沿用。下列比例是考试要求给出的知识模块大约分值比例；平台将其作为客观题抽题参考，题数、题型和自测评分不等同于正式笔试。后续年度按当年官方文件复核。

- 计算机基础知识，约 15%：发展与应用、进制转换、数值和字符编码、信息单位。练习时写出位权和换算步骤，明确符号位与计量单位。
- 计算机软硬件基础，约 20%：系统结构、硬件功能、软件与操作系统、Windows、数字媒体。重点辨认功能归属，理解采样、量化、像素与位深。
- 办公自动化，约 35%：Word 编辑与排版、表格图文、目录和邮件合并；Excel 引用、函数、数据整理与图表；PowerPoint 母版、版式、动画和放映。结合软件实际操作复习。
- 网络与信息安全，约 10%：网络模型、拓扑、设备、IP 和域名、Internet 服务、检索、病毒防护、个人信息与社会责任。以基础原理和应用判断为主。
- 算法与程序设计，约 10%：计算思维、算法描述与复杂度、程序翻译、三种基本结构、查找排序和流程图。通过变量变化表检查执行结果与边界条件。
- 数据库技术，约 5%：数据库系统、数据模型、E-R 图、选择、投影和连接。使用小表格辨认行、列与关联操作。
- 计算机新技术，约 5%：云服务及部署模式、大数据、物联网和人工智能。用场景理解技术用途、层次与信息责任。

页面“考试与证书指南”包含上述考点与练习建议。官方笔试还可能包含填空、简答、设计和综合应用等题型；平台提供客观题与下述精讲填空练习，仍应配合文字作答和软件操作训练。

Excel 的相对、绝对和混合引用各一课；考纲列出的 ABS、SUM、SUMIF、AVERAGE、COUNT、COUNTIF、VLOOKUP、IF、MAX、MIN、RANK、YEAR、MONTH、DAY、MID、LEFT、RIGHT、MOD 各一课。条件格式、数据导入、工作表保护与打印也各自成课。题目明确引用区域与直接参数、精确与近似查找、并列名次、负数 MOD、前导零等适用条件。

数制题明确位数与编码，媒体容量题明确未压缩及忽略额外结构的前提；算法题明确变量初值、循环边界和编号规则。关系投影题使用经典集合去重语义，不与 SQL 默认结果混淆。云部署模式和服务模式按不同维度判断。

会员切换到“四川省专升本 · 计算机基础”，从 VIP 的 AI 精讲与练习入口学习；App 中入口称“AI 精炼”。读完当前小节后点击“我学完了，开始练习”，练习仅选本节题目，每次五道，按记录优先安排未练或答错题。同一知识点的其他小节不会自动标为已读。学习和作答按账号、科目及小节隔离，切回科目可继续已有记录。

课程稿由 Codex 原创编写，按考纲、稳定知识规则和例题计算核对。课程种子保留核对理由及来源，管理预览标明“课程稿核对”，不作为平台上游 AI 独立审核记录。材料不是官方真题，也不代表已经完成真实模型答疑与判分质量验收。

维护文件：`scripts/study-content/sichuan-*.mjs` 保存各科原创课程稿；`server/study-curricula/sichuan-upgrading-computer.json` 保存拆分目录；`server/study-seeds/sichuan-upgrading-computer.json` 保存讲解、题目及核对记录。运行 `npm run study:sichuan` 可重建目录与课程种子，结构与题数检查失败会停止。修改后运行 `npm run verify`。

完整服务端与两套网页构建需一起同步，重启服务时自动补齐课程，不需要逐课调用平台 AI。已有有效发布版及下架记录会保留，原网络工程师课程 ID 和版本不变。v0.4.0 App 可通过共用学习接口读取新增课程；v0.4.1 同步提供会员兑换码购买入口。启用步骤见[精讲与练习部署说明](vip-subjective-study.md#验证与启用)和[v0.4.1 发布说明](release-v0.4.1.md)。

本地检查通过：题库结构与移动端类型检查、单元及接口检查、电脑与移动网页构建、电脑浏览器课程流程、Chromium/WebKit 移动学习流程和苹果网页布局检查。专升本专项检查覆盖完整拆课、代表性数值与函数、逐节解锁、提交前答案隐藏、跨科目隔离、下架保留以及新版本生成发布。检查使用隔离账号与数据库，不写入线上学习记录。

## 题库与共用规则

客观题模块可用 206 题：100 道专升本原创题、45 道现有原创题的引用，以及 61 道西昌学院 2011 年真题。共用题来自 MS Office（29 题）、网络工程师（10 题）和 HCIA（6 题），均经过范围筛选；未核验汇编与厂商配置题没有纳入本次共用清单。上面的 846 道精讲填空题存入独立课程内容包，不加入这项客观题统计。

共用题保持原 ID、题干、选项、答案、解析和来源信息，数据库只存一份。每个考试可以给同一题配置自己的章节、二级目录和知识点；原证书的分类保持有效。同一账号对同一 ID 的作答、收藏和错题沿用现有记录，不重复累计成两道题。

引用清单位于 `server/question-banks/sichuan-upgrading-computer/questions/shared.json`。新增引用必须指向已有题目，并填写当前考试的完整分类；加载时会检查引用存在、无重复、分类符合目录和大纲。

原创题和引用目录可以通过 `node scripts/build-sichuan-upgrading-bank.js` 重建。指南单独维护，不会被该脚本覆盖。题库目标数 300 为平台扩充目标，不代表正式试卷题量。
