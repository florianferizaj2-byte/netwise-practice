# Web 刷题即时反馈与背题模式

本说明记录 Web 刷题修复及本地验证。使用隔离测试账号和数据库，不调用收费模型；本地验收与 GitHub 提交不代表生产网站已部署。

## 卡顿原因与处理

原来的提交过程为：保存作答 → 取得判分 → 刷新总览、错题列表和整份题库 → 解除全局忙碌状态。即使页面已经显示正确答案，“下一题”仍然要等全部刷新完成。

现在普通练习提前准备当前题及后两题的标准答案，最多在当前组件内存中保留六题；快速跳题会取消不再需要的准备请求。考试、互动教学的小测不使用这条答案准备路径。预读结果不会写入普通题库缓存或整批写入浏览器存储。

提交后用已准备的答案立即显示反馈，同时后台保存作答。没有准备成功时，直接等待原来的服务端判分接口，不额外阻塞。最终判分、错题记录与学习任务进度仍由服务端决定，正确率和已答题数只统计服务端确认的作答。

成功作答后更新本轮状态，离开练习时统一刷新总览。每次切题不重新请求完整题库、总览或错题列表。后台响应按题目 ID 归位，不受当前题号改变影响。

## 保存与兼容

- `POST /api/attempts` 增加可选 UUID 字段 `clientAttemptId`。服务端将标识按账号隔离，同一次作答重试返回原记录；改变已使用标识对应的题目或答案返回 409。旧 App 可以继续省略此字段。
- 保存中或失败的内容不计为已保存成绩；页面显示状态和重试入口。刷新后保留提交标识，重试可恢复丢失的回执，不重复记题。
- 离开练习后到达的保存结果仅更新对应轮次的浏览器检查点，不覆盖新一轮练习。未同步的进度会保留恢复入口。
- 无数据库表结构变更。上线须同时更新 Web 和服务端，并重启 Node 服务；只替换前端会被旧服务端的严格请求校验拒绝。

## 背题与布局

练习页可切换“练习模式 / 背题模式”。背题直接显示标准答案和解析，回车或“下一题”按钮均可连续翻题，左右方向键可以回看。输入框、下拉框、来源折叠说明和弹窗保留原有键盘行为；模式与题号随本轮检查点恢复。背题浏览记录为“已看答案”，不增加正确作答、错题或学习任务完成数。

布局缩小章节图与标题，压缩选项和分区间距，修正右侧答题卡撑高左侧网格行造成的空白；来源说明可展开，答题卡每页 20 题，操作区在滚动时保持可达。兽医病例题的分组识别同时修复：病例首题排在后面时，仍能正确显示共用材料。

## 相关实现

- `src/components/practice-flow.jsx`：答案准备、后台保存、重试、模式和状态组件。
- `src/components/practice-viewport.jsx`：切题后定位题干与选项，处理迟到的答案、图片和视口尺寸变化；用户手动滚动后停止调整。
- `src/features/practice.jsx`、`src/features/veterinary-practice.jsx`：普通与兽医练习。
- `src/main.jsx`：离开练习时刷新汇总。
- `src/desktop-workspace.jsx`、`src/practice-progress.js`：检查点与模式恢复。
- `src/api.js`：只读答案准备不会使题库缓存失效。
- `src/question-utils.js`：病例组的识别与排序适配。
- `server/index.js`、`server/store.js`：可选提交标识与重复提交处理。
