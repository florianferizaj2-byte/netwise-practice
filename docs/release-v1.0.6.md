# 考匠 v1.0.6

Android `com.kaojiang.app`，版本 `1.0.6` / versionCode `39`。APK、Web 管理端和后端按现有 GitHub 分支交付，未另建 GitHub Release。线上服务器由维护者部署；手机实机验收未执行。

## 更新

- 新增连续答错第 1、2、3、4、5 次及以上五档语音。答对清零连错，答错清零连对；重复回执不重复计数，考试不触发练习语音。未配置的连错档保持安静，不播放答对提示音。
- 后台「语音包管理」逐场景选择固定播放一条或从勾选候选池中随机。随机只选当前场景的素材，多条时避免紧邻重复；每池最多 8 条，固定模式仅一条。
- 进入刷题、普通答对、连对和五档连错可独立配置、模拟试听、保存草稿和发布。第5档明确包含第5次及以上。
- APK 下载/更新完整语音包后才启用，本地校验和离线播放机制不变，答题时没有新音频请求。旧版 1.0.5 支持基础语音，但连错与新配置需升级至 1.0.6，再下载最新包。
- 兼容旧语音包和旧管理请求，新字段为可选扩展；同一原始请求的幂等签名不因默认填入新字段而改变。保留账号、积分、素材和发布版。
- 仅更新应用本身的版本，恢复 clone/defaults/mkdirp 三个依赖的正确锁文件版本标记；新增依赖版本与下载地址一致性检查，防止全局替换版本号再次误改。

## 部署与使用（服务器操作未执行）

拉取 `codex/v1.0.1-blue-web-backend` 分支，保留现有 `.env`、DATA_DIR 数据库和 voice-packs/assets；安装根目录依赖并构建，再用现有方式重启服务。

```bash
npm ci
npm run build
```

部署后进入 Web 管理端「用户与运营 → 语音包管理」，为各档连错选择语音、确定固定/随机和候选池，再发布。手机安装 v1.0.6，在设置中更新/下载该语音包即可。无需清库，不自动将用户电脑上的原录音复制到生产服务器。
