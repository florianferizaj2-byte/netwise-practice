# 虚拟定位学习

## 安卓版每日专项刷题前置条件

新入口、刷题页面和资格同步仅由 `.android` 文件接入。网页版 App 保留原有页面和流程，不引入本门槛。

进入前须登录，并从当前证书选择一个知识点，随机抽取 30 道不重复、有解析、能即时判分的客观题。保留完整共用材料题组；不足 30 道或不能完整组为 30 道的知识点不可选，不会从其他知识点凑数。

- 不设正确率门槛，也不要求错题重答正确。每题前台可见阅读至少 6 秒后才能提交；答错后须在解析可见时阅读至少 8 秒，确认继续后计入完成。
- 离开当前学习页、解析移出屏幕、切到后台或断线停留不增加有效阅读时间。服务端使用有序、单题单阶段的心跳及服务器经过时间校验；重复提交不重复写作答、不增加题数。
- 进度保存在服务器，普通作答与错题仍进入原有学习记录，不消耗 AI 积分。完成 30 道后按账号、证书、北京时间自然日开放；当天可重复进入，次日需重新完成。
- 原生桥接只接受服务端验证的一次性通行凭据，不再提供无条件打开入口。原生页面、悬浮启动和服务启动独立检查日资格。切换账号/证书、退出登录、进程重启或当日资格过期会撤销本机内存授权；进程重启后只需联网重新核验当天资格，不重复刷已完成的 30 道。
- 资格核验需要配套新版后端和重新构建 Android 客户端；不上传定位坐标，不把账号 Bearer 密钥或刷题解锁标记写入本模块本地存储。

入口完成前置学习后，仍需确认下面原有的学习用途协议；通过刷题或确认协议都不会自动开始模拟定位。

考匠安卓端的本地 Expo 模块。入口在“练习”的章节目录底部，名称是“虚拟定位学习”；每次进入先显示“学习用途与免责协议”，明确仅供学习使用，严禁用于校园跑作弊。同意后进入原生页面，首页只有“开始”“结束”两个主按钮，底部文字入口“使用教程”展示开发者选项、定位/通知权限和后台运行设置。

不同意则返回，不会开始模拟位置；同意也不会自动开始。重新进入需要再次同意，页面因旋转而重建会保留本次选择，不写入永久同意记录。协议仅为用途告知，不能据此声称技术上能识别或阻止第三方违规使用。

## 悬浮控制与进度

“使用教程”新增“悬浮窗”开关和权限设置入口。首次开启需允许“显示在其他应用上层”和精确位置；开启控制本身不会开始模拟定位。悬浮窗只有一个可拖动的按钮，未运行显示“开始”，运行后显示“结束 · 进度%”。首页和通知同步显示百分比，按已完成的路线距离计算。

新开启空闲悬浮窗时弹出“等待定位成功后再开启虚拟定位”。关闭提醒不会自动开始；请先在需要测试的页面确认定位成功。教程和空闲通知保留同样提醒，不检测或宣称其他应用已经定位成功。运行中的路线重新显示悬浮控制时，不阻挡“结束”。

每次点击悬浮“开始”仍需确认学习用途协议，服务继续检查精确位置权限、系统定位开关和模拟定位选择。点“结束”撤销模拟位置并释放运行唤醒锁，悬浮按钮保留并变回“开始”；到终点自动完成时保存 100%。再次开始从起点重跑。

长按关闭悬浮窗。运行中的路线继续，可以从首页或通知结束；空闲时关闭悬浮窗会退出本模块前台服务。拒绝悬浮权限时，普通首页的开始/结束仍可使用。

悬浮窗在教程页面可见时创建前台定位会话，之后在同一个服务中切换运行/空闲。空闲时不注入位置、不持有运行唤醒锁，保留控制与可关闭的通知；新系统使用与窗口类型匹配的显示/窗口上下文。

定位执行仍在本地，无卡密、地图或独立桌面图标。学习进度和进入资格使用宿主考匠的账号与服务器；原生桥接仅联网核验当天通行凭据，不上传坐标。

## 内置路线

文件 `android/src/main/assets/kaojiang-route-player.rplroute.json` 原样来自用户提供的“路线 10-12 22_50.rplroute.json”。24 个 WGS84 点，12 km/h，单次按顺序移动，到终点自动结束。SHA-256：

`8a3fc98a9886572f3d28dd0d29b577adc5d5dbf603df7f92cd672633ccff4edb`

再次点“开始”从起点重新运行。换内置路线需替换该资源并重新构建宿主；本版本没有路线编辑或导入界面。

## 接入方式

模块位于 Expo 默认的 `mobile/modules/` 目录，`expo-module.config.json` 声明原生 `AceExamRoutePlayer` 模块。Expo Autolinking 会在原生构建和 prebuild 中发现它，无需修改生成的 `mobile/android` 文件或手工注册 MainApplication。

`mobile/src/components/RoutePlayerChapter.tsx` 是章节入口，`PracticeHubScreen.tsx` 通过列表页脚展示它。入口仅在本地模块存在的安卓版中显示，网页、iOS 与未包含模块的旧客户端不显示；不会修改服务端题库、题量、答题记录或学习进度。

开发调用：

```ts
import { openRoutePlayer, routePlayerAvailable } from './modules/route-player/index.android';
import { locationLearningApi } from './src/api/locationLearning.android';
// Only from the completed daily study screen. The server independently checks it.
if (routePlayerAvailable()) await openRoutePlayer(await locationLearningApi.locationLearningOpenCredentials());
```

模块清单只追加必要的模拟定位、精确位置、前台定位服务、通知及唤醒锁权限，不覆盖考匠的网络权限、应用图标、主题、包名或启动入口。活动和服务不对其他应用导出。教程动态读取宿主名称，所以开发者选项中应选择“考匠”。

后台通过前台定位服务运行，通知中可以“结束”。强行停止或系统结束进程后不会自行从起点重跑。厂商省电设置仍需按手机实际菜单确认，不能保证所有手机锁屏长期运行。

## 本地资料

仅存储最近坐标、运行标记/进度、悬浮窗选项与位置和本模块的权限提示状态；协议同意仅为进程内临时授权，不持久化。不记录账号、卡密、设备标识或运行历史，不上传定位数据。Android 的正常模拟位置标记保持不变。

核心路线算法适配自当前工作区的 route-location 开源工程，许可原文保留在 `LICENSE`。安卓原生编译、桥接自动发现、路线与协议测试和 TypeScript 检查的结果见 [接入说明](../../../docs/ROUTE-PLAYER-INTEGRATION.md)。宿主安装包版本为 v0.4.5 / versionCode 29，构建与验收状态见 [版本说明](../../../docs/release-v0.4.5.md)。

教程依据：[Android 开发者选项](https://developer.android.google.cn/studio/debug/dev-options?hl=zh-cn)、[前台定位服务](https://developer.android.google.cn/develop/background-work/services/fgs/service-types?hl=zh-cn)、[电池优化](https://developer.android.google.cn/training/monitoring-device-state/doze-standby?hl=zh-cn)。
