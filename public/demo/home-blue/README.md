在项目根目录启动预览：

```powershell
node scripts/preview-home-blue.mjs
```

页面延续蓝白设计和每章的大小 SVG 插画，W、X、P 保留悬停动效。考试试卷、秒表及收藏插画也是代码绘制的 SVG，悬停有轻微动效。公开题库快照位于 `question-data.js`：七章、206 题，包含单选、多选、判断。模拟考试按快照中的 18 个分组选择范围，界面题量与实际题库一致。

证书选择是独立页面，顶部备考按钮、全局搜索与登录页“更多考试与证书”均可进入。支持证书/科目/别名搜索、专升本/软考/认证考试分类、地区筛选、键盘选择、当前选择预览和最近备考。八个方向中，四川计算机有完整刷题与精讲，网络工程师有精讲及逐空练习；四个软考预留方向保持准备状态，HCIA-Datacom 和 NCRE 二级 Office 可查看已制作的章节插画，当前 demo 的学习入口尚未接入。预留方向不能进入学习，也不请求不存在的内容。

章节插画覆盖除执业兽医外现有四类证书的 **44 章**：四川计算机7章、网络工程师10章、HCIA22章、NCRE5章。每章按主题选用固定 SVG，卡片小图与主视觉共用同一实现；网络模型、交换、VLAN、生成树、聚合、地址、路由、OSPF、IPv6、安全、服务、WLAN、运维、自动化，以及 Word/Excel/PowerPoint 有各自图标。支持悬停、键盘聚焦、点击播放；离开后停止，系统和设置减少动画时禁用。图标仅为章节插画，互动教学图解仍由独立安全渲染器生成。

AI 页的章节目录与标题显示小/大图标，点击可预览当前证书所有章节；证书页新增“查看全部章节图标”及总览入口。HCIA与NCRE仅新增图标预览，不将其他证书的学习记录或题库当作它们的数据。未来四个软考预留方向尚无项目章节目录，不编造章节清单；可通过同一注册表扩展。

`scripts/export-demo-chapter-visuals.mjs` 从题库 manifest 和现有网络工程师目录导出公开章名、知识主题及固定插画键，不导出题目、答案或用户数据。`--check` 检查来源一致性。`chapter-visuals.js/css` 管理绘制、统一尺寸和有限动效。`test/home-blue-chapter-visuals.e2e.js` 逐一检查44章的小图、大图、动画、SVG合法性、唯一ID、搜索、320/375/768/1280/1672宽度、浅深色及减少动画，并遍历现有AI课程17章的图标关联。结果在 `outputs/home-blue-demo/chapter-visuals-e2e.json`，证书选择与普通精讲回归均通过。

选择仅预览，点击学习入口或“进入学习”才切换已开放目标、保存最近备考并同步默认方向。网络工程师的普通题库、错题、组卷等未开放入口显示明确的准备状态，不展示或使用四川题库；切换回来保留原有会话、草稿和统计。两门精讲课程继续保留各自的学习进度。设置默认方向与顶部名称同步，清理或重置会恢复四川计算机。插画使用代码绘制 SVG，卡片反馈遵循减少动画，支持浅色/深色和字号设置。目录配置集中在 certificates.js 中，后续接入内容时可扩展可用路由。

登录页采用与学习空间一致的蓝白设计，首屏结合介绍、代码绘制的学习插画和紧凑表单，下方有五题试做、功能入口、备考方向搜索和 Web 学习介绍。支持登录/注册切换、键盘操作、密码显示、注册确认密码与协议校验、体验账号填入及账号帮助。提交仅进入学习界面；不接入正式认证，不创建真实账号，不发送或保存账号、密码或令牌。

勾选记住体验状态时保存本地体验标记，未勾选时标记仅保留在当前会话。免费试做复用公开题库，包含单选、多选和判断，支持选择、判分、解析、题目回看、五题报告及切换计算机/网络示例题组。试做记录仅留在本页，刷新重置，不修改章节进度或错题记录。功能卡片连接已有页面；软考入口提供网络题组示例。当前开发范围仍是 Web。可从学习空间右上角个人信息弹窗打开登录预览。

刷题支持顺序/随机、未做/错题范围、题量配置、答题卡跳转、键盘选择、判分与解析、背题、收藏、反馈、本轮报告和错题再练。背题更新学习进度，不计入作答正确率；普通练习计时在离开练习页或页面不可见时暂停。

错题本是独立总览入口，点击侧栏、首页复习按钮或搜索结果均先进入总览，不自动开始刷题。七章汇总、待巩固/已掌握/全部分类、关键词、章节与题型筛选、错误次数/时间排序、分页和全选均可使用。支持复习当前范围/所选内容、顺序/随机、5/10/20/30/全部题量、查看解析及上次错误选择、收藏、标记掌握、移出与撤销。答错自动收录并累计次数，答对自动掌握；移出后答对保持移出，重新答错再次收录。手动管理不修改既有作答统计；总览、章节错题范围、首页和侧栏计数一致。复习、刷新、报告回顾与返回都保留错题本导航归属，旧错题记录会自动迁移。撤销旧管理操作不会覆盖较新的作答状态。

VIP 卡片分别采用蓝色盾牌、紫色钻石和金色皇冠，图标由 SVG 代码绘制。悬停或键盘聚焦时触发浮起、切面闪光及皇冠弹起等动效；切换套餐时右侧图标、配色和参考价同步过渡。静止时不循环播放，并遵循系统减少动态效果设置。

VIP 会员页面采用参考图的三档示例套餐：基础/进阶/尊享，参考价为 19/39/79，30 天有效期及 100/300/1000 次演示月额度。支持套餐选择与保存、购买预览、生成/复制/填入 DEMO 卡密、输入校验、一次性兑换、会员状态/有效期/额度、兑换记录和会员说明。已有有效会员再次兑换需先确认更新类型与周期；过期和额度用尽也有对应提示。会员页、侧栏、首页和搜索的 AI 入口统一进入独立精讲页面。浏览已审核精讲与巩固练习不扣额度；主动获取一条老师示例回答使用 1 次本地演示额度。

会员购买、兑换和额度完全在当前浏览器演示，不产生付款，也不使用正式会员账号或真实卡密；仅接受当前浏览器生成的 DEMO 卡密。页面明确标注示例价格和本地体验。刷新保留会员状态，重置演示会清除这些记录。

AI 精讲采用左侧章节目录、右侧学习内容的布局，支持软考网络工程师（10 章、147 小节、882 道填空练习）与四川专升本计算机（7 章、141 小节、846 道填空练习）。目录按章、分组和子课时显示；OSI 七层分别成节，四川长知识点按独立课时拆开。支持章节选择、关键词搜索、空结果恢复、知识点收藏及只看收藏。AI 知识点收藏保存在本页目录，普通题目的收藏保持原有流程。进入、切换知识点不会自动记为学完；明确点击学完再更新学习进度。

普通精讲改为逐段阅读，每次只展示一个要点，最后一段呈现例子与易混提醒；支持上一段、下一段和刷新续读。路由优先级示例保留短结论与展开说明。内容快照通过 `node scripts/export-home-blue-ai.mjs` 从现有已审核种子导出，导出时校验内容结构、审核结果及当前目录版本，不包含审核过程、参考资料或任何用户数据。仅在打开精讲页时加载所选课程，失败可重试，快速切换不会串课。

新增完整「VLAN 广播域」互动课程：按基础选择深度，分为广播转发、VLAN 隔离、Access 归属三个概念。每段讲解后先答理解小测，再用变式题检验；不同错项进入对应的错因补课。两次变式仍未答对会记为待巩固，完整学完不等于全部掌握。新增统一注册渲染器支持 ExplanationCard、KnowledgeCard、ComparisonTable、NetworkDiagram、MiniQuiz、FeedbackCard、LessonProgress。广播路径由代码绘制的 SVG 展示；从 A/C 发出广播时，箭头、接收端和入口排除与实际端口 VLAN 归属一致。仅在讲解和补课时可以演示广播，小测作答前不显示判分结果。没有添加普通题目中的题目图表。

互动课程使用独立的 Express/SQLite 本地服务，标准答案与分支保留在 `server/demo-tutor/`，不放入 public。JSON Schema 可从 `/api/demo/tutor/v1/schema` 获取；内容与公开响应在服务端校验，再由固定组件渲染，文本安全转义。状态转移、判分、错因、掌握程度和幂等请求由 TutorEngine 管理。匿名会话使用 HttpOnly/SameSite cookie 隔离，保存在 `outputs/home-blue-demo/tutor-demo.sqlite`，不打开正式数据库，不创建真实会员或账号；闲置记录在 30 天后定期清理。刷新、跨页和服务重启后均可恢复；失败保留当前内容/选择，支持重试与先阅读，不本地猜测判分。演示课程每日最多重新创建 20 次、每分钟 90 次修改操作。重置演示数据会清理当前浏览器关联的互动课记录。

本阶段使用审核内容缓存与服务端规则教学，不调用收费模型。`/api/demo/tutor/v1/usage` 按匿名浏览器记录实际课程数、规则判分次数、审核内容读取次数、AI 请求、Token 和成本；当前 AI 请求/Token/成本如实为 0。正式 DeepSeek、会员权限及收费额度沿用项目原有机制，本次不接入；详情见 `docs/demo-ai-tutor.md`。

普通刷题工具栏新增「AI 精讲」，按当前题目匹配同章节知识点；返回保留练习会话、题号与选择。未交卷的模拟考试不提供精讲入口。

巩固练习每节六题，基础/理解/应用各两题，题干中的空与单独输入框一一对应。支持逐空必填提示、草稿保存、题号跳转、跳过补答、回看精讲、重新作答和本节报告。与预留答案完全一致的空直接得分；有出入的文字、别名、空格等显示待语义复核，当前本地 demo 不调用模型、不假装已完成复核、不直接判错。逐空结果显示自己的答案、参考答案与解释，报告区分已确认正确、待复核和未答。重复提交不重复记录，不影响原有章节练习统计或错题本。

问 AI 老师提供三种按当前知识点展开的示例回答，需有效演示会员；仅主动获取新示例回答时扣演示额度，同一弹窗中已获取的回答不可重复扣除。自由提问暂不生成答案、不扣额度。打开弹窗、切换目录、阅读、精确答案判分均不扣额度。聊天内容不写入浏览器存储，也没有正式 AI 请求。新页显示当前演示会员的真实剩余额度，支持会员到期/额度用尽提示。课程进度、收藏、草稿和结果按课程及内容版本保存，刷新续学，设置重置会一起清除。

学习计划支持周历、每日任务、任务续练、完成同步、添加任务、自主学习标记、删除撤销、调整周期/每日时间和复习路线。已完成、进行中和手动任务会在调整计划时保留。

模拟考试支持跨章节选择知识点、搜索与章节筛选、分组全选、移除选择、试卷命名、20/30/50 题、30/45/60 分钟及三种题型组合。可用题量不足时按实际数量组卷，并显示提示。试卷概览与生成的题目分配一致，题目不重复。未交卷考试可以从组卷页继续，开始按钮不会覆盖正在进行的考试。可在交卷后重新组卷。

考试答案即时保存为草稿，交卷前可以回改，成绩与解析只在交卷后显示。考试倒计时采用固定截止时间，离开页面、刷新或关闭后重开都不重新开始计时；超时会在页面运行或重新打开时自动交卷，统计只更新一次。报告包含成绩、正确/错误/未答、知识点表现、逐题解析与本卷错题再练，考试记录保存在当前浏览器。演示计分规则为每题等分、满分 100、多选必须完全匹配、未答为零分；不是正式考试评分方案。最多保留最近 40 份已结束的练习或考试及未结束会话。

收藏页支持题目/知识点分类、关键词搜索、章节与题型筛选、收藏时间/章节排序、分页、详情及更多操作。全选作用于当前筛选下的全部内容；所选项可批量练习、取消收藏，取消后提示条可撤销。右侧练习支持随机/顺序、全部/未练、5/10/20/30/全部题量；知识点练习会合并相关题目并去重。刷题中的星标与收藏页共用同一记录。可通过知识点面板的加号添加收藏。

全新的演示数据包含 12 道示例收藏和 4 个知识点，已有题目收藏会保留；清空后的刷新不会自动重新填充。空收藏时可点击“添加示例收藏”预览列表设计。收藏时间示例仅用于展示，实际星标操作会记录当前时间。

设置是独立页面，按参考图分为个人资料、学习偏好、账号安全、显示设置及通知提醒。浅色/深色/跟随系统、标准/较大/大号文字和减少动画可即时预览，点击保存后在刷新和其他页面保留。未保存的编辑在本次页面使用中保留，离开设置后使用已保存外观。减少动画同时遵循系统设置，覆盖插画、VIP、登录和页面过渡。字号调整保留插画文字尺寸。共享外观文件 `appearance.css` 可用 `node scripts/build-home-blue-appearance.mjs` 重新生成。

每次题量支持 10/20/30，并同步章节与收藏的练习配置；题量不足时按实际数量开始。作答后解析可以默认收起，并手动展开；自动下一题会停留 3 秒，点击“留在这题”、操作其他按钮、切换页面或隐藏页面时取消，避免后台切题。上述解析/自动切题偏好也覆盖 AI 逐空练习；模拟考试仍在交卷后才显示答案，不使用自动切题。

记住学习位置开启时，无指定页面或登录进入学习空间会继续上一次学习页面和题目；关闭后从初始位置开始，保留作答记录。未交卷模拟考试的题目位置、草稿和截止时间不因关闭记忆而重置。默认网络工程师方向进入已开放的 AI 精讲空间，四川计算机进入首页。显式链接到某个页面仍以链接为准。

学习提醒与计划页面共用开关/时间，在页面打开时到点提示，每天最多一次，不请求系统通知权限。消息通知控制当前浏览器内的学习里程碑和演示会员消息，顶部铃铛可查看、标记已读和清空。关闭消息不会关闭独立的每日学习提醒。

编辑资料支持昵称、签名与头像配色的本地保存，输入经过安全输出处理。密码修改提供校验与取消流程，输入不发送、不保存，关闭弹窗清空，也不修改正式密码。设备页面展示当前浏览器体验；没有服务器设备记录。退出清除体验标记并返回登录页，学习记录保留。协议、隐私和关于入口说明演示范围。恢复默认偏好需保存后生效；重置全部演示数据需在弹窗确认，清除学习/AI/收藏/会员/资料/设置并恢复初始示例。存储失败会明确提示。

普通学习进度、计划、收藏与反馈保存于当前浏览器独立的 demo 数据中；VLAN 互动课状态保存在上述本地演示服务中，刷新可继续。初始统计为演示进度，不连接账号。学习提醒仅在页面打开时显示，不发送系统通知；普通反馈不发送到服务器。设置中的“重置”恢复初始演示状态。本次开发范围为 Web 演示，没有发布或部署正式站点。
