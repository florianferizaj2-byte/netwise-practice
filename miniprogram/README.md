# 考匠微信小程序

这是基于 `mobile/` Expo 移动端 UI 重新实现的原生微信小程序前端。它复用现有 Node 后端，学习数据仍归属于原来的考匠 `user_id`。

## 本地打开

1. 安装微信开发者工具。
2. 导入本目录 `miniprogram/`。
3. 将 `project.config.json` 里的 `appid` 换成自己的小程序 AppID；没有 AppID 时可以先使用开发者工具的测试号预览 UI。
4. 正式真机请求前，在微信公众平台配置 `https://aceexam.top` 为 request 合法域名。

## 微信账号关联

小程序第一次调用 `wx.login()` 后，服务端会识别微信身份。如果该身份尚未绑定考匠账号，小程序会显示“绑定已有账号”或“注册新账号”。绑定成功后，网页端、Android App 和小程序共用同一个账号数据。

服务端需要在 `.env` 配置：

```text
WECHAT_MINIPROGRAM_APP_ID=...
WECHAT_MINIPROGRAM_APP_SECRET=...
```

AppSecret 只放在服务端，不能写进小程序代码。

## 当前页面

- 微信登录、已有账号绑定、新账号注册
- 证书选择
- 今日学习概览
- 顺序/随机刷题、错题复习、答案解析
- 模拟考试入口
- 社区文字消息
- 我的、账号、证书、社区昵称、退出登录
- 会员权益、购买兑换码链接复制、输入兑换码开通与续期

社区图片、AI 操作和完整考试会话可以继续沿用同一套接口，在第一版 UI 验证后补齐对应的小程序能力。

## 会员购买与兑换

购买地址为 [考匠兑换码商店](https://catfk.com/shop/aceexam)。“我的 → 会员与兑换码”和兑换弹窗中的购买按钮会复制链接，并提示粘贴到浏览器购买；购买后回到小程序输入兑换码。成功后显示会员等级及到期时间，刷新账号权益；请求失败保留兑换码供重试。

小程序通过现有登录会话调用 `/api/account/entitlements` 和 `/api/account/redeem`，与网页、Android 共用绑定的考匠账号。链接不带账号或兑换码参数。新版源码需另行提交小程序发布；本地接口与复制链接检查不代表微信真机或正式审核已完成。
